# 제27회 카일라이 모바일 미션 웹 로컬 데모

Figma 학생 화면의 형태와 주요 전환을 실제 브라우저에서 확인하기 위한 정적 로컬 데모입니다. 실제 로그인, NFC, AWS 연동은 포함하지 않습니다.

## 바로 확인하기

`index.html`을 브라우저로 열면 됩니다. 별도 설치나 빌드 과정이 없습니다. 로그인 화면에는 아무 값이나 입력하면 됩니다.

로컬 서버로 확인하려면 이 폴더에서 다음 명령을 실행하세요.

```bash
python3 -m http.server 4173
```

그다음 브라우저에서 `http://localhost:4173`을 엽니다.

## 포함된 흐름

- 로그인 및 빈 입력 오류
- 칸이나 건물을 직접 누르는 개인 게임판과 팝업형 미션 안내
- 맨 뒤에서 시계방향으로 배치된 문기부스·공연·방문 미션 12개
- 0/12, 건물 없는 빈 보드로 시작
- 방문 미션의 NFC 태깅 처리 중 → 자동 성공 → 1층 건물 표시
- 점수형 최대 6층, 방문·공연 미션은 1층
- 팝업 오른쪽 위 완료·미완료 상태 표시
- 공연 코드 입력 미리보기
- 12개 미션 전체 완료 화면
- 하단 제작 문구와 로그아웃(진행 상태 초기화)

왼쪽 바로가기와 미리보기 틀 없이 학생용 웹 화면만 표시합니다. 문기부스 팝업은 하단 닫기와 상단 × 버튼으로 닫을 수 있습니다.

## NFC 데모 범위

현재 NFC API나 태그 인식 기능은 없습니다. 방문 미션에서 NFC 태깅을 누르면 약 1.45초 동안 처리 화면을 보여준 뒤 항상 성공 상태로 이동합니다. 추후 실제 연동 시 startProcessing() 부분을 NFC 검증 요청으로 교체하면 됩니다.
